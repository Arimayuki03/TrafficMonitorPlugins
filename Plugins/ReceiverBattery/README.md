# ReceiverBattery 外设电量插件

在 TrafficMonitor 任务栏中显示无线外设的电量。插件不依赖厂商驱动，直接通过 HID / XInput 读取。

* 版本：V1.03
* 下载链接：[Release ReceiverBattery_V1.03](https://github.com/Arimayuki03/TrafficMonitorPlugins/releases/tag/ReceiverBattery_V1.03)

## 显示项目

插件只提供一个任务栏项目“外设电量”，默认显示：

    外设: 2.4G 100%

在插件选项中选择显示设备后，会切换为罗技或手柄：

    外设: 罗技 15%
    外设: 手柄 有线

- 自动：优先 2.4G 接收器，其次罗技设备，最后手柄
- 2.4G 接收器：AULA / Compx、ATK / VXE / VGN 等
- 罗技设备：HID++ 2.0 / 1.0（Unifying / Lightspeed / Bolt / 蓝牙）
- 手柄：XInput；无线手柄显示档位换算后的百分比，有线手柄显示“有线”

鼠标提示中会同时列出三类设备的当前电量，便于快速查看。

在“同时显示”中勾选任意多个设备后，一个任务栏项目会同时显示这些设备：

    外设: 2.4G 100% | 罗技 90% | 手柄 有线

也可以只勾选其中两项，例如：

    外设: 2.4G 100% | 罗技 90%

## 已实测设备

- AULA F99 Pro 2.4G 接收器（VID 3554 / PID FA09，report ID 0x13，命令 0x4A）
- 罗技 G Pro Wireless（USB 接收器 046D:C539，HID++ 2.0 0x1001 电压 4071 mV → 90%）
- 罗技 Signature Plus M750（蓝牙 046D:B02C，HID++ 2.0 0x1004 统一电池 → 55%）
- 北通阿修罗 A1T2（XInput dongle 把自己报告为有线设备，系统不提供电池百分比；显示“有线”）

同时连接多只罗技鼠标时，插件优先使用 USB 接收器上的设备，其次才使用蓝牙设备；鼠标提示中会显示具体型号。

## 协议要点

### AULA / Compx 2.4G

- 顶层集合：Usage Page 0xFF02、Usage 0x0002
- 20 字节中断报告，Report ID 0x13
- 请求：13 4A 01 00 00 ... 校验（0x4A 表示读电量）
- 应答：13 4A 01 00 02 电量 标志 ...，最后一字节为前 19 字节和的低 8 位
- 标志 0x10 表示正在充电，标志 0x01 表示电池供电

    request:  13 4A 01 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 5E
    response: 13 4A 01 00 02 64 01 00 00 00 00 00 00 00 00 00 00 00 00 C5

### ATK / VXE / VGN 2.4G

- 17 字节协议：Usage Page 0xFF02，Report ID 0x08，命令 0x04；应答第 6 字节为电量
- 64 字节协议：Usage Page 0xFF05，Report ID 0x08，命令 0x72；应答第 7 字节为电量

### 罗技 HID++

- 从设备索引 0xFF 开始，再尝试 1 到 6
- 读取 Feature 0x1004（统一电池，**function 1 get_status**）或 0x1000（电池状态，function 0）
- 0x1004 的 payload 为 `电量百分比 / 粗略档位 / 充电状态`；0x1000 为 `电量百分比 / 下一档位 / 充电状态`
- 仅提供 0x1001 电池电压的设备（例如 G Pro Wireless）按锂电池放电曲线换算成百分比
- 短报文 Report ID 0x10（7 字节），长报文 0x11（20 字节）
- 旧设备回退到 HID++ 1.0 寄存器 0x0D / 0x07

### XInput 手柄

- 动态加载 xinput1_4.dll / xinput1_3.dll / xinput9_1_0.dll
- 无线手柄使用 XInputGetBatteryInformation 的档位（空 / 低 / 中 / 满）换算成约 0 / 25 / 60 / 100%
- BATTERY_TYPE_WIRED 显示“有线”，不伪造百分比

## 设置

插件选项中可以配置：

- 设备检测：显示当前检测到的 2.4G 接收器、罗技设备与手柄，可点击“重新检测”刷新
- 显示设备（自动 / 2.4G / 罗技 / 手柄）：全部不勾选“同时显示”时生效
- 同时显示：分别勾选 2.4G / 罗技 / 手柄，可任意组合；在一个任务栏项目中用 `|` 分隔显示
- 是否在鼠标提示中显示详细信息
- 是否读取标准 HID 电量设备：用于没有专用协议的 2.4G 键鼠，作为通用回退；罗技、手柄不受影响
- 刷新间隔：输入框直接输入 3～300 秒

设置窗口会按当前显示器的 DPI 动态计算字体、行高和控件宽度，支持 100%～200% 及以上缩放以及多显示器不同 DPI 的情况；窗口大小和位置会限制在显示器工作区内。

配置文件为 TrafficMonitor 配置目录下的 ReceiverBattery.dll.ini。

## 稳定性说明

- 查询线程延迟到主程序启动完成后的 DataRequired 才启动，并先等待 500ms。
- 使用主程序绘制文本，不做自定义绘制，不返回自定义图标。
- 鼠标提示只保留四行短文本，避免与其他插件提示叠加后过长。

## 已知限制

- 只提供电池电压的罗技设备（例如 G Pro Wireless）会按锂电池放电曲线换算成百分比，结果可能与 G HUB 相差 1～2%。
- 键盘 / 鼠标休眠时 2.4G 接收器可能完全不回应，此时保留上一次电量。
- 2.4G 键盘插线充电时，部分固件会关闭 2.4G 通道，电量会暂时停留在上次值。
- XInput 只提供粗略档位，无法得到精确百分比。
